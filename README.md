# Hotel Website

A multi-page hotel website developed using PHP, HTML, CSS, JavaScript, and MySQL.

## Features

* User registration and login
* Browse hotel rooms and room details
* Single, Double, and Twin room pages
* Hotel facilities and services
* Room booking and reservation system
* View personal bookings
* Contact page
* Admin panel for managing rooms and reservations

## Technologies

* HTML
* CSS
* JavaScript
* PHP
* MySQL

## Project Structure

The project includes user-facing pages, room and booking sections, and an admin panel for managing hotel information and reservations.

## Database

MySQL is used to store and manage the project's data.

## Running the Project

The project requires a PHP and MySQL server environment. It can be run locally using tools such as XAMPP.
